# Vietnam commune and ward data

`vietnam_wards.json` contains the 3,321 commune and ward names, parent province/city names, and representative coordinates from the [Vietnam Administrative Divisions dataset](https://github.com/open-admin-data/vietnam-administrative-divisions/tree/54cdb052284b02e75dfaa44089ca383aa12c57db/data/all-ward.json), pinned to commit `54cdb052284b02e75dfaa44089ca383aa12c57db`.

The source dataset is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). This application keeps only the fields it uses and converts coordinates to numbers.
